# Exploit Policy

## Reporting an Exploit

If you encounter an exploit, please use [this form](https://docs.google.com/forms/d/e/1FAIpQLSeqVo47dZ4X2yztpweZTkVkTXUqusPo0I965dG3fqe1R3A6MQ/viewform?usp=dialog) instead of reporting it as an issue.

Exploits include (but are not limited to) duping, cheese spots, cheese strats, etc.
